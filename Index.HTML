024.1 — Conceptos, funciones y características

¿Qué es HTML y para qué sirve aquí?

HTML (HyperText Markup Language) es el lenguaje de marcado que define la estructura y el significado del contenido de una página web: qué es un título, qué es una lista, qué es una tabla o un enlace. No se encarga del diseño visual (eso lo hace CSS) ni del comportamiento (eso lo hace JavaScript), pero sin HTML no hay página que mostrar.

Aplicado al transporte urbano

En este sitio, HTML permite organizar la información propia del tema:

  • Cada ruta como un elemento de lista o fila de tabla.
  • Los horarios y tarifas en tablas con encabezados claros.
  • Un formulario para que el usuario consulte o reserve un viaje.
  • Enlaces internos para moverse entre secciones, como transbordar entre líneas.

Características de HTML usadas

  1. Etiquetas semánticas (header, nav, main, section, footer).
  2. Jerarquía de contenido con encabezados h1–h3.
  3. Listas ordenadas y no ordenadas para pasos y ventajas.
  4. Tablas para datos tabulares (horarios, tarifas).
  5. Formularios para recibir datos del usuario.
  6. Integración con JavaScript para procesar información.
034.3 — Etiquetas, formato, listas, imágenes y vínculos

Rutas y ventajas del transporte público

Movilizarse en transporte público reduce el tráfico y la contaminación, y suele ser más económico que el vehículo particular.

Ventajas de usar transporte público

  • Menor costo por viaje frente al carro propio.
  • Reduce la congestión vehicular en horas pico.
  • Menor huella de carbono por pasajero transportado.
  • Rutas fijas que facilitan planificar el tiempo de viaje.

Pasos para usar la tarjeta MetroCard

  1. Adquiere tu tarjeta en una estación del Metro.
  2. Recárgala con el monto que necesites.
  3. Pasa la tarjeta por el lector al entrar a la estación.
  4. Aborda el vagón y desciende en tu parada.
